# 🐍 Curso de Python em Vídeo

Este repositório foi criado para armazenar os meus códigos, exercícios e primeiros contatos com a linguagem **Python**, desenvolvidos principalmente durante o acompanhamento do curso da plataforma **Curso em Vídeo**.

## 🚀 O que este repositório contém?

O projeto documenta a minha evolução na programação, partindo do básico até a manipulação de dados e estruturas de repetição/condições.

*   **Primeiros Passos:** Scripts iniciais para entender a sintaxe, entrada e saída de dados.
*   **Exercícios Práticos:** Resolução de desafios propostos para fixação do conteúdo.
*   **Manipulação de Dados:** Primeiros contatos com variáveis, tipos primitivos e operações matemáticas.

## 📁 Estrutura de Arquivos

*   `primeiroscomandos.py`: Testes iniciais com comandos básicos do Python.
*   `primeiroscontantocomdados.py`: Práticas envolvendo entrada, validação e manipulação de tipos de dados.
*   `exer115.txt`: Arquivo de texto associado a exercícios práticos (como sistemas de cadastro ou manipulação de arquivos).
*   `cursoemvideopython/`: Pasta dedicada a organizar os módulos e desafios do curso.

## 🛠️ Como executar os scripts

Para rodar os códigos localmente, você precisa ter o **Python 3** instalado em sua máquina.

1. Clone o repositório:
   ```bash
   git clone https://github.com/GustavoFTI43/Curso-de-python-em-video.git
   ```

2. Acesse a pasta do projeto:
   ```bash
   cd Curso-de-python-em-video
   ```

3. Execute qualquer arquivo utilizando o terminal:
   ```bash
   python primeiroscomandos.py
   ```
